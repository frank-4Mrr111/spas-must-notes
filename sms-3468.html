Glossary - SMS 3468

Asset: something that gives future cash. Bond: loan to government / company, pays coupon + face. Equity / share: part-ownership of a company. Derivative: value comes from another asset. Forward / future: agree now to buy / sell later at fixed price. Option: right, not duty, to buy (call) or sell (put). Swap: exchange cashflows. Portfolio: collection of assets. Diversification: spread risk, do not put all eggs in one basket. Risk: here, SD of return. Return: gain / loss as %. CAPM: model linking risk (beta) to expected return. Beta: how much asset moves with market. ALM: Asset-Liability Management - match assets to liabilities. Duration: how sensitive bond price is to yield. Yield: return on bond if held to maturity. 【entity-NSE¦canonical_name=NSE】: Nairobi Securities Exchange. Topic 1: Introduction to Investment - Time Value, Assets, Risk and Return

Estimated time: ~30 minutes | Objectives: Define investment, explain time value, distinguish asset classes, explain risk vs return.

Investment = give up money now, get more later. But later is uncertain. That is risk.

Time value: Money now is worth more than money later. FV = PV (1 + i)^n.

Example: PV 100000, i=8%, n=3 years. FV = 100000 x 1.08^3 = 100000 x 1.259712 = 125971.

Asset classes: Cash, Bonds, Equities, Property, Commodities. Higher return usually = higher risk.

Risk vs Return: Risk = SD of return. Return = gain as %. No free lunch - high return without risk does not last.

Topic 2: Bonds - Price, Yield, Duration, Convexity

Estimated time: ~40 minutes | Objectives: Explain bonds, calculate bond price, explain yield, duration, convexity.

Bond = you lend money, you get coupon + face back.

Price: Price = sum Coupon / (1 + y)^t + Face / (1 + y)^n. Price falls when yield rises.

Example: Face 100000, Coupon 10% = 10000 per year, 2 years, Yield 8%. Price = 10000/1.08 + 110000/1.08^2 = 9259 + 94307 = 103566.

Yield to maturity: Yield that makes price = cashflows. Yield = coupon rate = price = face (par). Yield < coupon = price > face (premium). Yield > coupon = price < face (discount).

Duration: Weighted average time to cashflows. Longer duration = price moves more when yield moves. Convexity: curve, not straight line - duration is only first estimate.

Topic 3: Equities, Portfolio Theory and CAPM

Estimated time: ~40 minutes | Objectives: Explain equities, calculate portfolio return and variance, explain CAPM and beta.

Equity = own part of company. Price moves with profit, market, news.

Portfolio return: E(Rp) = w1 E(R1) + w2 E(R2).

Portfolio variance (2 assets): Var = w1^2 Var1 + w2^2 Var2 + 2 w1 w2 Cov. Cov = rho x SD1 x SD2.

Example: w1=0.6, SD1=20%, w2=0.4, SD2=10%, rho=0.5. Var = 0.36x400 + 0.16x100 + 2x0.6x0.4x0.5x20x10 = 144 + 16 + 48 = 208. SD = 14.42%.

Diversification: If rho < 1, portfolio SD < weighted average SD. Risk falls without losing all return.

CAPM: E(R) = Rf + beta (Rm - Rf). Beta = how much asset moves with market. Beta=1 = moves with market. Beta=0 = no market risk.

Topic 4: Derivatives - Forwards, Futures, Options, Swaps

Estimated time: ~35 minutes | Objectives: Explain derivatives, calculate forward price, calculate option payoff.

Derivative = value comes from another asset. Used to hedge or to speculate.

Forward / Future: Agree now, buy / sell later at fixed price F. F = S (1 + r)^T (no dividends). Example: S=100, r=10%, T=1 year. F = 100 x 1.10 = 110.

Call: Right to buy at K. Payoff = max(S - K, 0). Example: K=100, S=120. Payoff = 20. If S=90, payoff = 0.

Put: Right to sell at K. Payoff = max(K - S, 0). Example: K=100, S=90. Payoff = 10.

Swap: Exchange cashflows. Example: Fixed rate for floating rate. Hedging: Use derivative to reduce risk. Speculation: Use derivative to bet.

Topic 5: Portfolio Management - ALM, Diversification, Performance

Estimated time: ~40 minutes | Objectives: Explain portfolio management, ALM, diversification, performance measures.

Portfolio management = choose assets, watch them, rebalance.

Steps: 1. Know client - goal, time, risk. 2. Set policy - weights. 3. Choose assets. 4. Rebalance - sell winners, buy losers to keep weights. 5. Measure performance.

ALM: Asset-Liability Management. Match assets to liabilities. Pension must pay old people every month - need cash, not only long bonds. Insurer must pay claims - need liquid assets.

Performance: Sharpe = (Rp - Rf) / SDp. Higher Sharpe = more return per risk. Example: Rp=12%, Rf=6%, SD=10%. Sharpe = (12-6)/10 = 0.6.

Diversification: Across assets, sectors, countries. Do not put all in one share.

Topic 6: Investment in Practice - NSE, Kenya, Regulation

Estimated time: ~30 minutes | Objectives: Explain Kenya investment market, NSE, regulation, apply portfolio return.

Kenya has real markets - NSE, Treasury bills and bonds, SACCOs, pensions.

NSE: Nairobi Securities Exchange - buy / sell shares, bonds. 【entity-NSE¦canonical_name=NSE】 20, NASI indices.

Government: Treasury bills (91, 182, 364 days), Treasury bonds (long). Low risk, low return, used as Rf.

Regulators: CMA (capital markets), CBK (banks, T-bills), 【entity-RBA¦canonical_name=RBA】 (pensions), 【entity-IRA¦canonical_name=IRA】 (insurance). They protect investors.

Kenya problems: Low liquidity, few listed companies, high interest rates, inflation, currency risk, political risk.

Pensions: NSSF, private pensions. Must diversify, must match long liabilities.
