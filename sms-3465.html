Formula Sheet - SMS 3465

Credibility premium: P = Z x Xbar + (1 - Z) x M | Z = credibility factor, Xbar = own mean, M = manual / group mean | Full credibility (claims): n_0 = (z / k)^2 x (sigma^2 / mu^2) | 95%: z=1.96 | Partial credibility: Z = sqrt(n / n_0) | Buhlmann: Z = n / (n + K), K = v / a | Buhlmann-Straub: Z = m / (m + K) with exposures | Aggregate loss: S = X1 + ... + XN | E(S) = E(N) x E(X) | Var(S) = E(N) Var(X) + Var(N) E(X)^2 | Poisson: P(N=n) = e^-lambda lambda^n / n! | Exponential: f(x) = (1/theta) e^-x/theta, Mean = theta

Glossary - SMS 3465

Credibility: how much to trust own data. Manual rate: group / industry rate. Experience rate: own rate. Full credibility: enough data to trust fully. Partial credibility: blend own + manual. Buhlmann: credibility model using variance parts. Loss model: model for claims. Frequency: number of claims. Severity: size of each claim. Aggregate loss: total claims. MLE: maximum likelihood estimation - fit model to data. Goodness of fit: does model match data? Tail: large claims. Exposure: units at risk. Risk premium: expected loss per exposure.

Topic 1: Introduction to Credibility - Why Blend Own and Group Experience

Estimated time: ~30 minutes | Objectives: Define credibility, explain why we blend, explain credibility factor Z.

A small matatu SACCO has 2 years of claims. Is that enough to set its premium? No - one big claim would double its rate. Too unfair. Use group average too. Blend them.

Credibility formula: Premium = Z x Own Mean + (1 - Z) x Manual Mean. Z between 0 and 1. Z=1: trust own data fully. Z=0: ignore own data, use group.

Example: Own mean 5000, Manual mean 4000, Z=0.6. Premium = 0.6x5000 + 0.4x4000 = 3000 + 1600 = 4600.

When Z is high: Lots of data, stable data, own data is different from group. When Z is low: Little data, wild data, own data like group.

Topic 2: Limited Fluctuation Credibility - Full and Partial Credibility

Estimated time: ~40 minutes | Objectives: Explain limited fluctuation, calculate full credibility standard, calculate partial Z.

Limited fluctuation asks: How much data do I need before I trust my own mean fully?

Full credibility: n_0 = (z / k)^2 x (sigma^2 / mu^2). z = 1.96 for 95%, k = allowed error (e.g. 5% = 0.05). If you have n >= n_0, Z=1.

Example: mu=1000, sigma=2000, k=0.05, z=1.96. n_0 = (1.96/0.05)^2 x (2000^2 / 1000^2) = 1536.64 x 4 = 6147 claims. Need 6147 claims for full credibility.

Partial: If n < n_0, Z = sqrt(n / n_0). Example: n=1537, n_0=6147. Z = sqrt(0.25) = 0.5.

Topic 3: Buhlmann and Buhlmann-Straub Credibility

Estimated time: ~40 minutes | Objectives: Explain Buhlmann, calculate K and Z, explain Buhlmann-Straub with exposures.

Buhlmann is smarter. It uses variance: How much do groups differ (a)? How much does one group jump year to year (v)?

Buhlmann: Z = n / (n + K), K = v / a. v = expected process variance (within group), a = variance of hypothetical means (between groups).

Example: n=4 years, v=100, a=25. K = 100/25 = 4. Z = 4 / (4+4) = 0.5.

Buhlmann-Straub: Same idea, but with exposures m (e.g. number of cars). Z = m / (m + K). More exposure = more credibility. Used when groups have different sizes.

Premium: Still Z x Own + (1-Z) x Manual, but Z comes from Buhlmann, not from n_0.

Topic 4: Loss Models - Frequency, Severity, Aggregate Loss

Estimated time: ~35 minutes | Objectives: Explain frequency, severity, aggregate loss, calculate E(S) and Var(S).

Total claims S = sum of each claim. Two parts: How many claims (frequency N)? How big each claim (severity X)?

Frequency: Often Poisson: Mean = Var = lambda. Example: lambda=2 claims per year.

Severity: Often Exponential, Lognormal, Gamma, Pareto. Exponential mean = theta.

Aggregate: E(S) = E(N) x E(X). Var(S) = E(N) Var(X) + Var(N) E(X)^2.

Example: E(N)=10, E(X)=5000, Var(N)=10 (Poisson), Var(X)=25000000. E(S)=10x5000=50000. Var(S)=10x25000000 + 10x5000^2 = 250000000 + 250000000 = 500000000. SD = 22361.

Topic 5: Fitting Loss Models - MLE, Goodness of Fit, Tail

Estimated time: ~35 minutes | Objectives: Explain fitting, explain MLE, explain goodness of fit, explain tail and censoring.

Fitting = choose a model that matches your claims data. Then use it to price.

MLE: Maximum Likelihood Estimation - choose parameters that make your observed data most likely. Example: Exponential MLE: theta_hat = sample mean.

Goodness of fit: Does model match data? Tests: Chi-square, Kolmogorov-Smirnov, Anderson-Darling. Plot: QQ plot - points on line = good fit.

Tail: Large claims matter most. Pareto has heavy tail - more large claims than Exponential. Wrong tail = underprice large claims.

Censoring / Truncation: Censoring: you know claim > limit, but not exact. Truncation: you only see claims above deductible. Both must be handled in fitting.

Topic 6: Credibility and Loss Models in Practice - Premiums, Kenya

Estimated time: ~30 minutes | Objectives: Apply credibility and loss models to premiums, explain Kenya practice.

Premium = Expected Loss + Expenses + Profit + Risk margin. Credibility and loss models give Expected Loss.

Steps: 1. Fit loss model to claims. 2. Get E(S) per exposure. 3. Apply credibility - blend own E(S) with manual. 4. Add expenses, profit, margin. 5. Check: Is premium enough? Is it fair? Is it competitive?

Kenya: Motor insurance - many small claims, few large. Medical - rising costs. Data problems: short history, missing claims, fraud. Credibility helps when data is thin.

Bonus-malus: No-claim bonus = credibility in practice - good drivers get lower premium over time.
