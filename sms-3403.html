Formula Sheet - SMS 3403

Payoff: What each player gets for each combination | Nash: No player can gain by changing alone | Zero-sum: One gains what other loses, sum = 0 | Mixed strategy: Play A with prob p, B with prob 1-p | Expected payoff: p x Payoff A + (1-p) x Payoff B | Minimax: Maximin = Minimax at saddle point | Backward induction: Solve from end of tree backwards

Glossary - SMS 3403

Game: situation where outcome depends on all players choices. Player: decision maker. Strategy: plan of action. Payoff: reward for each outcome. Dominant strategy: best no matter what other does. Nash equilibrium: no one wants to change alone. Zero-sum: one gains, other loses same. Mixed strategy: randomise between strategies. Cooperation: players work together. Auction: bidding game. Backward induction: solve sequential game from end.

Topic 1: Introduction to Games - Players, Strategies, Payoffs

Estimated time: ~30 minutes | Objectives: Define game, identify players, strategies, payoffs, build a payoff matrix.

A game is any situation where your best choice depends on what someone else does. Two insurers setting premiums is a game. Two firms bidding is a game.

3 parts: 1. Players - who decides? 2. Strategies - what can each do? 3. Payoffs - what does each get for each combination?

Example - Two insurers: Each can Charge High or Charge Low. If both High: each gets 10. If both Low: each gets 4. If one High, one Low: Low gets 12, High gets 2. The matrix shows all 4 outcomes.

Topic 2: Dominant Strategies and Nash Equilibrium

Estimated time: ~35 minutes | Objectives: Explain dominant strategy, find Nash equilibrium, explain why Nash matters.

A dominant strategy is best no matter what the other player does. Nash equilibrium is where no one wants to change alone.

Find Nash: For each column, circle Row best payoff. For each row, circle Column best payoff. Any cell with both circled is Nash.

Example - Insurers: Both High: 10,10. Both Low: 4,4. One High, one Low: Low 12, High 2. Low is dominant for both - Low is best whether other is High or Low. Nash = Both Low (4,4), even though Both High (10,10) is better for both. That is the dilemma.

Topic 3: Zero-Sum Games and Mixed Strategies

Estimated time: ~40 minutes | Objectives: Explain zero-sum, find saddle point, calculate mixed strategy probabilities.

Zero-sum: one gains what the other loses. Total = 0. Think of two firms fighting for one contract - one wins, one loses.

Saddle point: Maximin = Minimax. Row player picks row with highest minimum. Column player picks column with lowest maximum. If they meet, that is saddle point - pure strategy Nash.

No saddle point? Use mixed strategy: Randomise. Example 2x2 game: Row plays A with prob p, B with 1-p. Choose p so Column is indifferent between its two strategies. Solve: Expected payoff to Column from C1 = Expected payoff from C2. That gives p.

Worked: Row payoffs: A/C1=6, A/C2=2, B/C1=1, B/C2=5. Column indifferent: 6p + 1(1-p) = 2p + 5(1-p). Left = 5p+1. Right = -3p+5. 5p+1 = -3p+5. 8p=4. p=0.5. Row plays A 50%, B 50%. Value = 5(0.5)+1 = 3.5.

Topic 4: Prisoners Dilemma and Repeated Games

Estimated time: ~30 minutes | Objectives: Explain Prisoners Dilemma, explain cooperation, explain repeated games and tit-for-tat.

Prisoners Dilemma: Both would be better cooperating, but each has incentive to defect. So both defect and both lose.

Classic: Two suspects. If both stay silent: 1 year each. If one confesses, other silent: confessor free, silent 10 years. If both confess: 5 years each. Confess is dominant. Nash = both confess (5,5), worse than both silent (1,1).

Insurance version: Two insurers. Cooperate = keep premiums high. Defect = undercut. Undercut is dominant. Both undercut, both earn little.

Repeated games: If game repeats, cooperation can work. Tit-for-tat: start cooperating, then copy what other did last time. Punishes cheating, rewards cooperation.

Topic 5: Sequential Games and Game Trees

Estimated time: ~35 minutes | Objectives: Explain sequential games, draw game tree, solve by backward induction.

Sequential game: players move one after another, not at same time. Example: Firm A enters market or not, then Firm B responds.

Game tree: Nodes = decisions, Branches = choices, Leaves = payoffs.

Backward induction: Start at end. At each last node, pick best move for player who moves there. Work backwards to start.

Example: A can Enter or Stay Out. If Stay Out: A 0, B 10. If Enter: B can Fight or Share. If Fight: A -2, B 2. If Share: A 5, B 5. B will Share (5 > 2). So A knows Enter gives 5, Stay Out gives 0. A Enters. Equilibrium: Enter, Share.

Topic 6: Game Theory in Insurance - Pricing, Reinsurance, Auctions

Estimated time: ~30 minutes | Objectives: Apply game theory to insurance pricing, reinsurance, auctions, explain collusion and regulation.

Game theory explains real insurance markets.

Pricing: Insurers undercut to win customers, but if all undercut, all lose. That is Prisoners Dilemma.

Reinsurance: Insurer and reinsurer bargain. Each wants better price. Nash bargaining splits surplus.

Auctions: Bidding for a contract is a game. Bid too high = lose. Bid too low = win but lose money. Winner's curse: winner overpays.

Collusion: Firms agreeing to keep prices high is cooperation. It helps firms, hurts customers. That is why competition law (in Kenya, Competition Authority) bans price-fixing.
