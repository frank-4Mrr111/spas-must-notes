Topic 1: Introduction to Information Systems

What is an Information System? An Information System (IS) is a set of people, data, software, hardware, and procedures that work together to collect data, turn it into information, and help people make decisions. No one part works alone. Hardware without software does nothing. Software without data has nothing to process. Data without people to use it is useless.

5 Components — Learn these 5, they answer Exercise 2:

  1. Hardware — computers, phones, servers. Job: store and run. Example in insurance: the computer that runs the policy system.
  2. Software — programs, e.g. Excel, policy system. Job: process data. Example: program that calculates premium.
  3. Data — raw facts: name, age, sum assured, premium paid. Job: what the system works on.
  4. People — users, managers, IT staff. Job: enter data, use information, maintain system.
  5. Procedures — rules / steps: "Enter policy within 24 hours, check age, save, backup." Job: make sure everyone does it the same way.

Data vs Information — Learn this, it answers Exercise 1:

Data = raw facts, no meaning yet. Example: 30, 100000, 2000 — just numbers. You do not know what they mean.

Information = data + meaning + context. Example: "A 30-year-old with sum assured 100,000 pays premium 2,000 per year." Now you understand it and you can decide.

Process: Data → Processing (sorting, calculating) → Information → Decision. Example: Data (ages + premiums of 1000 policies) → System adds them → Information (total premiums = 2,000,000) → Manager decides (we can pay claims).

Why does insurance need IS? 1) Speed: find a policy in seconds, not 30 minutes in paper files. 2) Accuracy: computer does not forget or mis-add like a tired human. 3) Reports: manager sees total premiums, total claims, profit in one report. 4) Memory: system remembers 100,000 policies, a human cannot.

Topic 2: Data, Databases and Data Management

What is a Database? A database is organised data stored so you can search it, update it, and protect it quickly. Think of it as a smart filing cabinet — not a pile of papers, but labelled drawers where you can find anything in seconds.

Key words — Learn these, they answer Exercises 3-4:

  • Table = one topic, e.g. Policies table. One table per topic.
  • Field / Column = one type of data, e.g. Name, Age, SumAssured.
  • Record / Row = one full item, e.g. one policy: P-102, Frank, 30, 100000.
  • Primary Key = unique ID for each row, never repeated, never blank. Example: PolicyNo. Why not Name? 1) Two people can have the same name — "Frank" appears twice, system would confuse them. 2) A person can change name (marriage) — then the key breaks. PolicyNo never changes and never repeats.
  • Query / Filter = question to the database. Example: "Show me all policies where Age > 60" → Filter: Age > 60 → System shows only those rows.

Worked Example — Same kind as Exercise 4: Policies table has PolicyNo, Name, Age. Question: Find policies where Age > 60. Answer in words: "Filter the Policies table where Age is greater than 60. Show PolicyNo, Name, Age for those rows only." If the table has 500 rows and 40 are over 60, the system shows 40 rows, not 500.

Data Management: 1) Enter data correctly (check age, check sum). 2) Update when it changes (address, premium). 3) Backup (copy, so if computer dies, data lives). 4) Control who can see/edit (only staff who need it).

Topic 3: Spreadsheets for Actuaries

What is a Spreadsheet? A grid of rows and columns (Excel / Google Sheets) where you can type data, write formulas, and the computer calculates automatically. Cell = one box, e.g. B2 = column B, row 2. Formula always starts with =.

Golden Rule — Learn this, it answers Exercise 5: Always use cell references, never type numbers inside a formula. Wrong: =2500+5000. Right: =SUM(B2:B5). Why? If one premium changes from 2500 to 3000, the wrong formula still says old total. The right formula updates automatically because it reads the cells.

Formulas you must know:

  • =SUM(B2:B5) = add all numbers from B2 to B5.
  • =AVERAGE(B2:B4) = add them, then divide by how many. Example: 2000, 3000, 5000 → Sum = 10000 → Divide by 3 → Average = 3333.33.
  • =IF = if condition true, do this, else do that. Example: =IF(Age>60, "Senior", "Young").
  • =VLOOKUP = find a value in a table.

Worked Example — Same kind as Exercise 5: Claims in C2:C4 = 12000, 18000, 15000. Question: What formula gives total? Answer: =SUM(C2:C4). The computer adds 12000+18000+15000 = 45000. You write the formula, not just 45000.

Worked Example — Same kind as Exercise 6: Premiums 2000, 3000, 5000. Average: Step 1: Sum = 2000+3000+5000 = 10000. Step 2: Count = 3. Step 3: Average = 10000 / 3 = 3333.33. Formula: =AVERAGE(B2:B4).

Topic 4: Actuarial Software and Programming Basics

What is Actuarial Software? Programs built for actuaries to model many policies at once: Excel, R, Python, and specialist systems like Prophet / MoSes. A program is a list of clear steps the computer follows exactly, every time, without getting tired.

Input → Process → Output — Learn this, it answers Exercise 8: Input = what you give the computer (age, sum assured). Process = what it does (premium = sum × rate). Output = what it gives you (premium). If input is wrong, output is wrong — computer does not know, it just follows steps. That is "Garbage In, Garbage Out".

Why software beats hand calculation — Learn this, it answers Exercise 7: 1) Speed: 100,000 policies in seconds, hand would take months. 2) Consistency: Same steps every time, no tired mistakes. 3) What-if: Change rate from 0.02 to 0.03, press Enter, all premiums update. By hand, you start again.

Worked Example — Same kind as Exercise 8: Calculate premium for one policy. Steps: Step 1: Input sum assured = 100,000, rate = 0.02. Step 2: Process: premium = 100,000 × 0.02 = 2,000. Step 3: Output: premium = 2,000. In Python, that is: premium = 100000 * 0.02. The actuary decided the rate. The computer just multiplied.

Topic 5: Data Security, Ethics and Privacy

What is it? Actuarial data is sensitive: names, ages, health, money, ID numbers. Security = protect it from loss / theft. Privacy = only collect and use what you need, only share with who needs it. Ethics = use it fairly, even when you could get away with unfair use.

Ways to protect data — Learn these, they answer Exercise 9:

  1. Passwords + Access control — only staff who need data can open it. Clerk sees policies, manager sees reports, IT sees system — not everyone sees everything.
  2. Backup — copy data to another safe place, so if computer dies / is stolen, data lives.
  3. Do not share / Do not download to personal phone / WhatsApp — work inside the system, not outside.
  4. Encryption — scramble data so even if stolen, thief cannot read it without key.

Ethics Example — Learn this, it answers Exercise 10: A colleague asks for a client's health data "just to check". Answer: No. Reasons: 1) You do not have the client's permission for that purpose. 2) You do not know if the colleague needs it for work. 3) If it leaks, the client is harmed and the company is blamed. The right way: colleague asks the manager, manager checks if access is needed, then gives limited access through the system, with a record.

Topic 6: Management Information Systems and Decision Support

What is MIS? Management Information System = system that turns raw data into reports for managers. Raw data = 100,000 rows, too many to read. MIS report = one page: total premiums, total claims, profit, number of new policies, number of claims. Manager reads the report, not the rows.

What is Decision Support / What-if? Manager asks "What if...?" and the system recalculates. Example: "What if claims rise 10%?" System: new claims = old claims × 1.10, new profit = premiums - new claims. Manager sees the new profit and decides: raise premiums? Cut costs? Keep as is?

Worked Example — Same kind as Exercise 11: Premiums = 14,500,000, Claims = 10,000,000. Profit = Premiums - Claims = 14,500,000 - 10,000,000 = 4,500,000. Formula: Profit = Total Premiums - Total Claims.

Worked Example — Same kind as Exercise 12: Raw data table: 100,000 rows, each row one policy. MIS report: 5 lines — Total Policies: 100,000, Total Premiums: 20,000,000, Total Claims: 12,000,000, Profit: 8,000,000, New Policies This Month: 500. Difference: Raw data = detail, MIS = summary for decision.
